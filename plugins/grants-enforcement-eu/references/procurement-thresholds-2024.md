# EU Procurement Thresholds & Flat-Rate Financial Corrections — 2024–2025

**Sources:**
- Procurement thresholds: Commission Delegated Regulation (EU) 2023/2495 adjusting thresholds under Directives 2014/24/EU, 2014/25/EU, and 2014/23/EU — applicable from 1 January 2024.
- Commission internal thresholds (FR 2018/1046 + RAP): DG BUDG guidance note on procurement procedures — verify current RAP version on EUR-Lex.
- Flat-rate corrections: Commission Implementing Decision C(2019)3452 on flat-rate financial corrections (grants); programme-specific implementing decisions per cohesion fund, Horizon Europe, and other programmes.
- **EUR-Lex reference:** Verify current versions before use.
- **Next threshold update:** 1 January 2026 (thresholds adjusted every two years).
- **Next corrections update:** As adopted per programme — check EUR-Lex for latest implementing decisions.

## Commission Internal Procurement Thresholds (FR 2018/1046 + RAP)

These apply to European Commission procurement. They differ from the public sector Directive thresholds applicable to member states.

| Contract type | Simplified (single quote) | Negotiated (single tender) | Negotiated (min. 3 tenderers) | Open / Restricted (TED publication) |
|---|---|---|---|---|
| Supplies and Services | < €15,000 | €15,000 – €60,000 | €60,000 – €139,000 | ≥ €139,000 |
| Works | < €15,000 | €15,000 – €100,000 | €100,000 – €5,382,000 | ≥ €5,382,000 |
| Specific contracts under a Framework Contract | Governed by FwC terms and original procedure — no separate threshold applies |

**Standstill period:** 14 calendar days after notification of award decision before signing (above-threshold contracts).
**Contract Award Notice publication:** Within 30 days of signing, for above-threshold contracts (TED/OJS).

## Flat-Rate Financial Corrections — Grants (Commission programmes)

### Principle

Where the full extent of an irregularity cannot be determined by item-by-item audit, a flat-rate correction is applied. The rate is set by reference to the risk level of the irregularity type. The legal basis is the programme-specific Financial Regulation and Commission implementing decisions.

### Standard flat-rate correction scale (cross-programme reference)

| Irregularity category | Flat rate |
|---|---|
| Serious deficiency in procurement — no competition at all (direct award without basis) | 100% |
| Serious deficiency — insufficient competition (negotiated without publication where not permitted) | 25% |
| Moderate deficiency — inadequate publication or insufficient time limits | 10% |
| Minor deficiency — non-substantial deviation from procedural rules | 5% |
| Ineligible costs — category entirely ineligible under funding rules | 100% of ineligible category |
| Ineligible costs — partial ineligibility (e.g., overheads, travel) | Item-by-item or flat rate as applicable |
| Conflict of interest — undisclosed, material influence on award | 100% of affected contract |
| Conflict of interest — potential but no demonstrated influence | 25% of affected contract |

> These rates apply where programme-specific implementing decisions do not set a different rate. Always check the programme-specific decision first (Horizon Europe, ERDF/CF, ESF+, EAGF/EAFRD each have dedicated implementing decisions).

### Horizon Europe specific corrections (Decision C(2019)3452 as updated)

| Error type | Flat rate |
|---|---|
| Personnel costs — no time-recording system | 100% of personnel costs |
| Personnel costs — incomplete time records | 10–25% depending on severity |
| Subcontracting without prior authorisation | 25% of subcontracted costs |
| Indirect costs — calculation error | Item-by-item |
| Non-compliance with visibility/communication obligations | Up to 2% of total eligible costs |

### Cohesion Funds (ERDF/CF/ESF+) — CPR 2021/1060 flat rates

Under Art. 104(1) CPR and Commission Implementing Regulation (EU) 2021/1155:

| Procurement irregularity | Flat-rate correction |
|---|---|
| Contract awarded without any competitive procedure | 100% |
| Contract awarded through negotiated procedure without justification | 25% |
| Unjustified exclusion of tenderer | 25% |
| Inadequate publication | 10% |
| Short timelines (below mandatory minimums) | 10% |
| Contract modification — substantial change without re-tendering | 25% of modified amount |
| Conflict of interest (proven) | 100% |
| Minor procedural irregularity | 2–5% |

## Art. 260 TFEU Penalty Coefficients (Infringement)

For reference by `infringement` skill. These derive from Commission Notice C(2023)1791 (replacing earlier notices).

### Daily penalty payment (Art. 260(2)/(3))

Formula: **n × b × c**

| Factor | Description | 2024 value |
|---|---|---|
| **n** | Seriousness coefficient (1–20) | Set case-by-case by Commission |
| **b** | Basic amount per day | €2,391,000 (uniform base, updated annually) |
| **c** | Country capacity factor (GDP + population) | See table below |

**Country capacity factors (c) — selected MS:**

| Member State | Factor c |
|---|---|
| Germany | 1.00 (reference) |
| France | 0.88 |
| Italy | 0.73 |
| Spain | 0.54 |
| Poland | 0.34 |
| Netherlands | 0.42 |
| Belgium | 0.29 |
| Sweden | 0.27 |
| Romania | 0.14 |
| Hungary | 0.12 |
| Luxembourg | 0.03 |

**Minimum daily penalty:** €3,386 (per Commission Notice — verify current Notice).

### Lump sum (Art. 260(2)/(3))

Formula: **n × (b/360) × d** where d = number of days of infringement.

Minimum lump sum per MS: set by Commission Notice — varies by MS (smallest MS ~€158,000; largest MS ~€2.1 million).

> **Always verify** the current Commission Notice (C-series OJ) before quoting penalty figures in any output. The basic amount and minimum lump sums are updated annually.

## How to Use This File in Skills

1. Read threshold values directly from the tables above — do not generate from training data.
2. Cite as: `(procurement-thresholds-2024.md — verify if after January 2026 for thresholds; verify latest Commission implementing decision for flat-rate corrections)`.
3. For Art. 260 penalties, read the country factor from the table; the seriousness coefficient is always case-specific and must be flagged `[review — Commission discretion]`.
4. For programme-specific flat-rate corrections, the table above is a cross-programme baseline. Always check the programme implementing decision for the actual applicable rate.
