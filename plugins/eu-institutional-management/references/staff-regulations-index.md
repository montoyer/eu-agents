# Staff Regulations & CEOS — Reference Index

Full authentic text of the **Staff Regulations of Officials of the EU** and the
**Conditions of Employment of Other Servants (CEOS)**, split one file per Title
and per Annex. Source: EUR-Lex consolidated text **CELEX `01962R0031`**,
consolidation date **01.01.2026**.

A consolidated text is a documentation tool with **no legal effect** — the
authentic version is the one published in the *Official Journal*. When citing
to a user, use `[Staff Regulations Art. XX — EUR-Lex 01962R0031, 01.01.2026]`
(or `[CEOS Art. XX — …]`).

> **How skills use this:** read the single file covering the Title/Annex you need
> rather than loading everything. Quote the article text from the file instead of
> reconstructing it from training data. Pay-scale figures are **not** here — they
> live in [staff-regulations-annex-i-2026.md](staff-regulations-annex-i-2026.md),
> which is maintained separately and updated each January.
